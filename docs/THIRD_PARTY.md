# Зависимости

Версии зафиксированы в `requirements.lock.txt`. Установка — через pip; wheel-архивы и окружение в репозиторий не включены. Лицензии библиотек сохраняются в установленном окружении.

Flask и NumPy — BSD; Matplotlib — лицензия Matplotlib; Plotly.py / Plotly.js, PyVISA и PyVISA-py — MIT; PyUSB — BSD; libusb-package — Apache-2.0. Включённая в libusb-package библиотека libusb — LGPL-2.1-or-later.

Драйверы и программы производителей не распространяются. Интерфейс и графики используют локальные ресурсы без внешних CDN.
